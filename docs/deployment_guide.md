# 现场部署指南 - 户外定时拍照系统

> 适用项目：基于 ESP32-S3 的太阳能供电户外长期独立运行定时拍照系统
> 文档版本：v1.0
> 配套文档：[固件烧录指南](flashing_guide.md) | [故障排查指南](troubleshooting.md)

本文档面向现场部署与运维人员，描述从选址、硬件安装、初次配置到现场上电的完整部署流程，确保设备在户外长期稳定运行。

---

## 1. 选址要求

正确的选址是户外长期稳定运行的前提。部署前需综合评估光照、视野、信号、环境与温度五项因素。

### 1.1 光照条件（太阳能供电关键）

| 要求项 | 指标 | 说明 |
|--------|------|------|
| 太阳能板朝向 | **朝南**（北半球） | 北半球朝南可获得最大日照 |
| 倾斜角度 | ≈ 当地纬度 ± 5° | 中纬度地区（中国大部分）建议 30°~45°；赤道接近水平；高纬度 45°~60° |
| 直射时长 | 每天至少 **4 小时**直射光 | 9:00~15:00 期间太阳能板上方无遮挡 |
| 遮挡排查 | 板面无树冠、建筑、山体阴影 | 冬季太阳高度角低，需按冬至日阴影校核 |

> **倾斜角度经验值**：北京（纬度 40°）建议 40°；上海（31°）建议 35°；广州（23°）建议 25°；高纬度地区冬季采光需增大角度。

### 1.2 视野要求（拍照效果）

- 摄像头朝向被监测目标场景（如工地、生态区、道路）。
- **避免逆光**：摄像头背对太阳方向拍摄，避免朝东/朝西正对日出日落。
- 视野范围内无近距离障碍物遮挡镜头（如树枝、蜘蛛网）。
- 如镜头可调，根据目标距离调整对焦。

### 1.3 信号强度（启用 WiFi 回传时）

| 要求项 | 指标 | 说明 |
|--------|------|------|
| 信号强度 | **≥ -75 dBm** | 低于此值上传成功率显著下降 |
| AP 距离 | 建议 **< 30 米** | 视墙体/障碍物衰减而定，空旷环境可达 50 米 |
| 障碍物 | 尽量减少墙壁、金属遮挡 | 金属外壳会屏蔽 WiFi，需用外接天线版本（-U 模组） |

> 若信号不达标，建议：① 调整设备位置靠近 AP；② 增加无线中继；③ 改用 LoRa 回传（未来扩展）；④ 关闭回传仅本地存储。

### 1.4 环境安全

- **避开积水**：不在低洼易涝处安装，电缆接头朝下避免雨水渗入。
- **避开落石**：不在松动的岩壁、悬崖下方安装。
- **防动物破坏**：避免啮齿类动物啃咬电缆，必要时加装金属护套；安装高度 ≥ 3m 可减少人为与动物干扰。
- **防风**：抱箍/壁挂安装需紧固，三脚架安装需配重防倾倒。

### 1.5 温度控制

- **避免阳光直射外壳**：优选树荫下、建筑北侧或自制遮阳棚下安装。
- **白色外壳**：反射阳光，外壳温升降低 10~15℃（本项目外壳已选白色 ABS+PC）。
- **环境温度范围**：-20℃ ~ +60℃（LiFePO4 电池放电温度限制）；高寒地区（<-10℃）需考虑低温加热片选配。
- **散热间隙**：外壳周围保留通风空间，不密闭包裹。

## 2. 硬件安装

### 2.1 三种安装方式

本项目外壳支持三种安装方式，详见 `hardware/enclosure_design.md`。

| 安装方式 | 适用场景 | 优势 | 劣势 | 操作难度 |
|----------|----------|------|------|----------|
| **抱箍安装** | 树干、电线杆、管道（Φ40~80mm） | 快速、通用、可拆卸、无需打孔 | 需匹配杆径 | ★☆☆ |
| **壁挂安装** | 墙壁、立柱侧面 | 稳固、防盗 | 需打孔膨胀螺丝 | ★★☆ |
| **三脚架安装** | 地面、临时部署、灵活调整位置 | 灵活、可移动、免破坏 | 易被盗、需配重 | ★☆☆ |

#### 2.1.1 抱箍安装步骤

1. 选择直径 Φ40~80mm 的杆/树，清理表面。
2. 将不锈钢抱箍（304，宽 15mm）穿过外壳背部 U 型卡槽。
3. 抱箍环绕杆体，初步拧紧螺母。
4. **调整太阳能板朝南**，外壳水平。
5. 对角线交替拧紧抱箍螺母，确保不松动。
6. 轻推外壳验证稳固性。

#### 2.1.2 壁挂安装步骤

1. 在墙面标记 4 个壁挂耳孔位（M4 螺丝孔距见外壳图纸）。
2. 用电钻打孔，植入 M4×30 不锈钢膨胀螺丝（木质墙面用 M4×20 自攻螺丝）。
3. 套上平垫 + 弹簧垫，将外壳壁挂耳挂在螺丝上。
4. 拧紧螺母，确保外壳贴墙不晃动。
5. 确认太阳能板朝南，电缆接头朝下。

#### 2.1.3 三脚架安装步骤

1. 展开标准相机三脚架，调整至所需高度，锁紧云台。
2. 将外壳底部 1/4-20 UNC 螺纹孔对准三脚架螺丝。
3. 旋紧固定，确认承重稳固（≥1kg）。
4. 调整云台角度使太阳能板朝南、摄像头朝向目标。
5. 三脚架腿加重物配重，防风吹倾倒。

> **防盗建议**：三脚架安装易被盗，仅建议临时部署。长期部署优先壁挂（高处）或抱箍（杆顶）。

### 2.2 太阳能板安装方向与角度

太阳能板采用外壳顶部嵌入式安装（详见外壳设计文档），出厂默认水平。高纬度地区可选用可调角度支架（0~45°）。

| 调整项 | 操作 | 验证方法 |
|--------|------|----------|
| 朝向 | 太阳能板正面朝**正南** | 用手机指南针确认正南方向 |
| 倾斜角 | 调节支架使板面与水平面夹角 ≈ 当地纬度 | 用手机水平仪/量角器 APP 测量 |
| 遮挡 | 9:00~15:00 板面无阴影 | 正午前后实地观察，或用太阳轨迹 APP 模拟 |

> **雨水自洁**：水平安装时雨水可冲刷板面灰尘；倾斜安装角度不宜过小（< 15°），否则灰尘易堆积。

### 2.3 摄像头视野调整

- 固定焦距镜头（OV2640 f=3.5mm）：视野固定，通过调整外壳朝向构图。
- **可调镜头**（若选配 AF 版本）：通过配置或现场微调对焦环，确保目标距离清晰。
- 拍照前清洁摄像头窗口玻璃（AR 镀膜光学玻璃），避免指纹/灰尘影响成像。
- 确认玻璃内侧无结露（防雾涂层 + 干燥剂）。

### 2.4 防水接头处理

太阳能板电缆通过 PG7 防水接头（IP68）引入外壳，密封处理至关重要：

1. 电缆穿过 PG7 接头时，剥离外皮长度适中，不损伤芯线。
2. **拧紧 PG7 螺母**至手拧不动后再加 1/4 圈，使橡胶芯抱紧电缆。
3. 电缆接头**朝下**安装，避免雨水沿电缆渗入。
4. 接头与外壳接缝处涂抹**户外硅胶密封胶**（道康宁 737 或等效），固化 24 小时后户外使用。
5. 检查密封圈（硅胶 O 圈，预压 20~25%）是否均匀受压，无卷边。

> **密封验收**：装配完成后做 IP65 喷水测试（喷嘴 Φ6.3mm，12.5L/min，3m 距离各方向 3min），确认内部无渗漏后方可部署。

## 3. 初次配置流程

部署前需完成电池充电、SD 卡准备、固件烧录与室内测试，确保设备功能正常后再赴现场安装。

### 3.1 充满电池

- **方式 A（推荐）**：用 USB 线连接设备充电口，通过 5V 充电器为 LiFePO4 电池充电（CN3791 充电管理），充电至满（电池电压 ≈ 3.65V）。
- **方式 B**：拆下 18650 电池，用专用 LiFePO4 充电器充电至 3.65V 后装回。

> LiFePO4 标称电压 3.2V，满电 3.65V，放电截止 2.5V。部署前电量建议 ≥ 80%。

### 3.2 SD 卡格式化与配置文件写入

1. 准备 MicroSD 卡（16~32GB，Class 10 / U1 及以上，推荐 SanDisk High Endurance 或工业级）。
2. 用电脑格式化为 **FAT32**（Windows 用 format；macOS/Linux 用 diskutil / mkfs.vfat；大于 32GB 需用专用工具如 Rufus 强制 FAT32）。
3. 在 SD 卡**根目录**创建 `config.json`，内容按部署需求填写（模板见第 4 节）。
4. 将 SD 卡插入设备 MicroSD 卡座（自弹式，推入锁定）。

### 3.3 烧录固件（如未预烧）

若设备未预烧固件，按 [固件烧录指南](flashing_guide.md) 执行：
```bash
cd firmware
idf.py -p /dev/ttyACM0 flash
```

### 3.4 室内测试

部署前必须在室内验证功能正常：

1. USB 连接设备，启动串口监控：`idf.py -p /dev/ttyACM0 monitor`
2. 上电后观察串口日志：
   - 确认 `RTC 时间` 正确（DS3231 已校时）。
   - 确认 `配置加载成功`（config.json 被正确读取）。
   - 确认 `电池电压` 合理（≥ 3.2V）。
   - 确认 `拍照成功` 且 `照片已保存` 路径正确。
3. 等待一个拍照周期（按 config.json 中 interval_minutes），确认定时唤醒正常。
4. 取出 SD 卡，用读卡器在电脑查看 `/photos/YYYYMMDD/HHMMSS.jpg` 照片：
   - 照片可正常打开，画面清晰，无花屏/全黑/全白。
   - 文件大小合理（UXGA JPEG 约 100~400KB）。
5. 若启用 WiFi 回传，确认服务器收到上传数据。

> **室内测试通过后方可赴现场安装**。若任何环节异常，先排查解决（参考 [故障排查指南](troubleshooting.md)）。

### 3.5 装入外壳与密封

1. 将 PCB 用 4×M2 铜柱 + 不锈钢螺丝固定到外壳下盖。
2. MCU 金属屏蔽罩顶部薄涂导热硅脂（信越 7762），接触外壳下盖散热。
3. 电池放入电池座，外包 5mm EVA 泡棉保温。
4. 电缆穿入 PG7 接头并拧紧密封。
5. 外壳内壁贴 1g 硅胶干燥剂包（3~6 个月更换）。
6. 合上下盖，密封圈涂少量硅油润滑，对角线交替拧紧螺丝（扭矩 0.2~0.3 N·m）。
7. 螺丝孔、PG7 接头缝隙涂户外密封胶，固化 24 小时。

### 3.6 现场安装固定

按第 2 节选择安装方式，现场固定设备：
- 调整太阳能板朝南、倾斜角合适。
- 调整摄像头朝向目标场景，避免逆光。
- 紧固所有螺丝与抱箍，验证稳固。

### 3.7 上电启动

1. 确认电池已装、SD 卡已插、外壳已密封。
2. 接通电源（接好太阳能板接线，或仅靠电池供电启动）。
3. 观察设备启动（无串口时看状态 LED，或等待预期拍照时间后取卡验证）。
4. 等待首次拍照周期到达，确认设备进入正常"醒→拍→存→睡"循环。

### 3.8 检查照片

部署后通过以下方式之一确认拍照正常：
- **取卡检查**（本地存储模式）：拔出 SD 卡用读卡器查看 `/photos/` 下照片。
- **WiFi 回传**（启用回传模式）：登录服务器查看上传记录。
- **配置门户状态查询**：长按 GPIO0 进配置门户，访问 `http://192.168.4.1/status` 查看电池与 SD 空间。

> 建议部署后 24~48 小时回访一次，确认前 1~2 天运行正常后再转为定期巡检。

## 4. config.json 模板

### 4.1 完整模板（本地存储，不回传）

适用于无 WiFi 环境或仅需本地存储的场景：

```json
{
  "interval_minutes": 30,
  "resolution": "1600x1200",
  "quality": 10,
  "upload_enabled": false,
  "wifi_ssid": "",
  "wifi_password": "",
  "server_url": ""
}
```

### 4.2 完整模板（启用 WiFi 回传）

适用于有 WiFi 覆盖、需远程查看照片的场景：

```json
{
  "interval_minutes": 30,
  "resolution": "1600x1200",
  "quality": 10,
  "upload_enabled": true,
  "wifi_ssid": "MyWiFiNetwork",
  "wifi_password": "MyWiFiPassword123",
  "server_url": "http://192.168.1.100:8080/upload"
}
```

### 4.3 字段说明

| 字段 | 类型 | 取值范围 | 默认值 | 说明 |
|------|------|----------|--------|------|
| `interval_minutes` | 整数 | 1 ~ 1440 | 5 | 拍照间隔（分钟）。30 = 每半小时一张，60 = 每小时一张 |
| `resolution` | 字符串 | `1600x1200` / `1280x1024` / `640x480` | `1600x1200` | UXGA（200万像素）/ SXGA / VGA；VGA 文件最小、传输最快 |
| `quality` | 整数 | 4 ~ 63 | 10 | JPEG 质量，**数值越小画质越高**；推荐 5~15 |
| `upload_enabled` | 布尔 | true / false | false | 是否启用 WiFi 回传；false 时仅本地存储，省电 |
| `wifi_ssid` | 字符串 | 最长 63 字符 | `""` | WiFi 网络名称；upload_enabled=true 时必填 |
| `wifi_password` | 字符串 | 最长 63 字符 | `""` | WiFi 密码 |
| `server_url` | 字符串 | 最长 127 字符 | `""` | 上传服务器 URL，照片以 image/jpeg POST 到该地址；upload_enabled=true 时必填 |

### 4.4 典型场景配置建议

| 场景 | interval | resolution | quality | upload | 说明 |
|------|----------|------------|---------|--------|------|
| 工地进度记录 | 60 min | 1600x1200 | 10 | false | 每小时一张，本地存储，SD 卡可存数年 |
| 生态延时摄影 | 10 min | 1600x1200 | 8 | false | 高频高清，本地存储 |
| 风景延时 | 30 min | 1600x1200 | 10 | false | 平衡存储与连贯性 |
| 远程监控（有 WiFi） | 30 min | 640x480 | 15 | true | 低分辨率省传输带宽 |
| 低电量省电模式 | 由固件自动调整 | — | — | — | 低电量时固件自动延长间隔跳过拍照 |

> **低电量保护**：当电池电压过低时，固件自动跳过拍照并延长唤醒间隔，保护电池。此行为由 `power_mgmt` 模块控制，无需手动配置。

## 7. 注意事项

### 7.1 防雷

- **雷暴高发区**避免在空旷高地、孤立大树顶部安装，优先靠近避雷设施。
- 太阳能板电缆建议串接浪涌保护器（可选），防止感应雷击损坏充电电路。
- 设备本身无防雷击设计，雷击损坏不在保修范围。

### 7.2 防盗

- 安装高度 ≥ 3m，减少人为接触。
- 壁挂/抱箍安装比三脚架更防盗。
- 三脚架临时部署需有人看管或加防盗锁。
- 外壳螺丝可选用防拆螺丝（异形头）增加拆卸难度。

### 7.3 防破坏

- 电缆走线隐蔽，避免暴露易被剪断。
- 外壳避免醒目颜色/反光，融入环境。
- 关键部署点可加装防护笼。

### 7.4 电池低温限制

LiFePO4 电池低温特性（详见 `hardware/BOM.md`）：

| 温度范围 | 充电 | 放电 | 说明 |
|----------|------|------|------|
| 0℃ ~ +45℃ | ✅ 正常 | ✅ 正常 | 最佳工作区间 |
| -10℃ ~ 0℃ | ⚠️ 受限 | ✅ 正常 | CN3791 通过 NTC 在 <0℃ 时停止充电，防止锂枝晶 |
| -20℃ ~ -10℃ | ❌ 禁止 | ⚠️ 容量降至 70% | 可维持运行但续航缩短 |
| < -20℃ | ❌ 禁止 | ❌ 暂停拍照 | 固件低温保护，仅维持 RTC |

> **高寒地区（<-10℃）部署**：① 电池外包 EVA 泡棉保温；② 选配 PTC 自限温加热片（5V 0.5W，温度 <-5℃ 时启动）；③ 增大太阳能板功率补偿低温发电衰减。

### 7.5 其他

- **SD 卡寿命**：户外长期频繁写入，务必使用 High Endurance 或工业级 SD 卡，普通卡 3~6 个月可能损坏。
- **干燥剂更换**：外壳内硅胶干燥剂每 3~6 个月更换一次，防止内部结露。
- **密封圈检查**：每年检查一次硅胶密封圈弹性，老化变硬需更换。
- **首次部署观察期**：建议部署后 24~48 小时回访，确认运行正常后转为定期巡检。
