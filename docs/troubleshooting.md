# 故障排查指南 - 户外定时拍照系统

> 适用项目：基于 ESP32-S3 的太阳能供电户外长期独立运行定时拍照系统
> 文档版本：v1.0
> 配套文档：[固件烧录指南](flashing_guide.md) | [现场部署指南](deployment_guide.md)

本文档面向现场运维人员，描述日志解读方法、常见故障排查、硬件诊断手段与维护周期建议，帮助快速定位与解决问题。

---

## 1. 日志解读

日志是排查问题的首要依据。系统通过 `logger` 组件将关键事件写入 SD 卡，同时输出到串口（ESP_LOG）。

### 1.1 日志位置

| 存储位置 | 路径 | 说明 |
|----------|------|------|
| SD 卡日志文件 | `/sdcard/logs/YYYYMMDD.log` | 按日期分文件，每日一个 |
| 串口实时输出 | UART0（GPIO43=TX, 115200bps） | 实时调试用，断电丢失 |

> **日志滚动**：单个日志文件超过 **1MB** 时自动滚动，重命名为 `YYYYMMDD_1.log`、`YYYYMMDD_2.log`……，保留当日完整日志。

### 1.2 日志格式

每行日志格式：

```
[YYYY-MM-DD HH:MM:SS] [LEVEL] [event] message
```

字段说明：

| 字段 | 说明 | 示例 |
|------|------|------|
| 时间戳 | 来自 DS3231 RTC（已注入 logger 时间源） | `2025-08-03 14:30:00` |
| 级别 | `INFO` / `WARN` / `ERROR` | `INFO` |
| 事件标签 | 标识事件类型 | `photo_saved` |
| 消息 | 具体内容（printf 格式） | `/sdcard/photos/20250803/143000.jpg (245680 bytes)` |

示例日志行：

```
[2025-08-03 14:30:00] [INFO] [boot] RTC 2025-08-03 14:30:00, Vbat 3.28V (85%), interval 30 min, res 1600x1200, upload 0
[2025-08-03 14:30:02] [INFO] [photo_saved] /sdcard/photos/20250803/143000.jpg (245680 bytes)
[2025-08-03 14:30:03] [INFO] [cycle_done] photo=/sdcard/photos/20250803/143000.jpg size=245680 interval=30 vbat=3.28
[2025-08-03 14:30:03] [INFO] [sleep] next wake in 30 min
```

### 1.3 常见日志事件类型

| 事件标签 | 级别 | 含义 | 出现阶段 |
|----------|------|------|----------|
| `boot` | INFO | 唤醒后记录 RTC 时间、电压、配置摘要 | 每次唤醒周期开始 |
| `config_portal` | INFO | 配置门户启动（GPIO0 长按触发） | 配置门户 |
| `config_saved` | INFO | 配置已保存（通过门户） | 配置门户保存 |
| `portal_started` | INFO | SoftAP 已启动，AP=OutdoorCam-XXXX | 配置门户 |
| `portal_timeout` | WARN | 配置门户 30 分钟无操作超时关闭 | 配置门户 |
| `battery` | WARN | 低电量跳过拍照 | 周期中电量检查 |
| `cleanup` | INFO/WARN | SD 卡空间清理（删除最早日期目录） | 周期中空间检查 |
| `photo_saved` | INFO | 照片保存成功，含路径与大小 | 拍照后 |
| `capture` | ERROR/WARN | 拍照失败（重试中或最终失败） | 拍照重试 |
| `camera` | ERROR | 摄像头初始化失败 | 摄像头初始化 |
| `sd` | ERROR | SD 卡初始化失败 | SD 卡初始化 |
| `storage` | ERROR | 照片写入失败 | 文件写入 |
| `upload` | INFO/WARN/ERROR | WiFi 回传结果（成功/失败/跳过） | WiFi 回传 |
| `cycle_done` | INFO | 周期完成，含照片路径、大小、间隔、电压 | 周期结束 |
| `sleep` | INFO | 进入深度睡眠，下次唤醒间隔 | 周期结束 |
| `rtc` | ERROR | RTC（DS3231）初始化失败 | 周期开始 |

### 1.4 如何通过日志判断问题

**排查思路**：导出 SD 卡日志 → 按时间定位异常段 → 看级别与事件标签 → 对应第 2 节表格处理。

| 日志特征 | 判断结论 |
|----------|----------|
| 长时间无 `boot` 记录 | 设备未唤醒（RTC 故障 / 电池耗尽 / 设备死机） |
| 有 `boot` 但无 `photo_saved` | 拍照环节失败，查 `capture` / `camera` / `sd` 错误日志 |
| `battery` WARN 频繁出现 | 电量持续偏低，查太阳能充电系统 |
| `capture` ERROR 连续多次 | 摄像头硬件故障，查排线 / 更换摄像头 |
| `storage` ERROR | SD 卡写入失败，查 SD 卡状态 |
| `upload` ERROR 但 `photo_saved` 正常 | 仅回传异常，照片已存本地，查 WiFi 信号 / 服务器 |
| `cleanup` WARN 频繁 | SD 卡频繁满，查容量管理或换更大 SD 卡 |
| 日志时间戳异常（如 1970 年或乱码） | RTC 时间丢失，查 CR2032 备用电池 |

## 2. 常见问题与解决

### 2.1 拍照与存储类

| 现象 | 可能原因 | 排查步骤 | 解决方法 |
|------|----------|----------|----------|
| 不拍照 | 摄像头初始化失败 | 查日志 `[camera] init failed`；检查 FPC 排线是否插紧 | 重新插拔摄像头排线；更换摄像头模组；确认 PSRAM 已启用 |
| 不拍照 | SD 卡未挂载 | 查日志 `[sd] init failed`；SD 卡是否 FAT32 格式 | 格式化 SD 卡为 FAT32；更换 SD 卡；检查 SD 卡座触点 |
| 不拍照 | 电池低电量 | 查日志 `battery skip capture` 与电压值；电源管理跳过拍照 | 充电；检查太阳能板是否遮挡/损坏；增大 interval 降低功耗 |
| 不拍照 | RTC 闹钟未触发 | 查日志无 `boot` 记录；检查 DS3231 I2C 通信 | 检查 RTC 排线；更换 DS3231；更换 CR2032 |
| 拍照但无文件 | SD 卡写入失败 | 查日志 `[storage] write failed`；SD 卡是否只读/写保护 | 解除 SD 卡写保护；更换 SD 卡；检查文件系统 |
| 拍照但无文件 | 日期目录创建失败 | 查日志；RTC 时间是否异常（如 1970 年） | 校时 RTC；更换 CR2032 |
| 照片模糊 | 镜头脏污 / 对焦不准 | 检查照片清晰度；检查摄像头窗口玻璃 | 清洁镜头与窗口玻璃；调整对焦环（可调镜头） |
| 照片全黑 | 摄像头未正常曝光 / 遮挡 | 检查照片；检查镜头是否被遮挡 | 清除镜头遮挡物；检查摄像头是否损坏 |
| 照片全白 / 过曝 | 强逆光 / 镜头直对阳光 | 检查照片与摄像头朝向 | 调整摄像头朝向，避免逆光 |

### 2.2 定时与时间类

| 现象 | 可能原因 | 排查步骤 | 解决方法 |
|------|----------|----------|----------|
| 不定时唤醒 | DS3231 故障 | 查日志 `[rtc] init failed`；I2C 通信失败 | 检查 RTC 排线与 I2C 接线（GPIO4/5）；更换 DS3231 |
| 不定时唤醒 | RTC 闹钟未设置 | 查日志是否执行到 `sleep`；固件异常退出 | 升级固件；查看是否触发兜底 5 分钟 timer 唤醒 |
| 时间错误 / 漂移大 | RTC 电池（CR2032）耗尽 | 查日志时间戳与实际时间偏差 | 更换 CR2032 纽扣电池；重新校时 |
| 时间归零（1970 年） | RTC 掉电后未校时 | 查日志时间戳异常 | 更换 CR2032；通过配置门户或串口重新设置 RTC 时间 |
| 唤醒间隔不符 | 配置 interval_minutes 错误 | 查 config.json 与日志 `interval` 值 | 修正 config.json；通过配置门户重新设置 |

### 2.3 系统与电源类

| 现象 | 可能原因 | 排查步骤 | 解决方法 |
|------|----------|----------|----------|
| 重启循环（boot loop） | 看门狗触发 / 某步骤卡死 | 查日志重复出现的 ERROR；串口看复位原因 | 升级固件；`erase-flash` 后重新烧录 |
| 重启循环 | 供电不足（拍照峰值电流） | 万用表测电池电压；查是否每次拍照后复位 | 充电；检查 470µF 储能电容；更换老化电池 |
| 设备无响应 | 电池完全耗尽 | 万用表测电池电压（< 2.5V） | 拆回充电；检查太阳能充电系统 |
| 设备无响应 | 固件死机 | USB 连接看日志；按 RST 复位 | 复位；重新烧录固件 |
| 电池不充电 | 太阳能板遮挡 / 损坏 | 万用表测太阳能板输出电压（应 ≥ 5V） | 清洁太阳能板面板；更换太阳能板 |
| 电池不充电 | CN3791 充电 IC 故障 | 万用表测充电电流；测 CN3791 引脚电压 | 检查充电电路；更换 CN3791 |
| 电池不充电 | 低温保护（< 0℃） | 查环境温度；CN3791 NTC 触发 | 等待温度回升；高寒区选配加热片 |
| 续航变短 | 电池老化 | 查日志电压趋势；测电池容量 | 更换 18650 电池（LiFePO4 循环 ≥2000 次） |

### 2.4 网络与存储管理类

| 现象 | 可能原因 | 排查步骤 | 解决方法 |
|------|----------|----------|----------|
| WiFi 不上传 | 信号弱 | 查日志 `upload connect failed`；测信号强度 | 调整设备位置靠近 AP；增加中继 |
| WiFi 不上传 | WiFi 密码错误 | 查日志 `connect failed`；核对 config.json | 修正 wifi_ssid / wifi_password；通过配置门户重设 |
| WiFi 不上传 | 服务器 URL 错误 / 不可达 | 查日志 `send failed`；浏览器测试服务器 | 修正 server_url；检查服务器运行状态 |
| WiFi 不上传 | upload_enabled=false | 查 config.json 与日志 `skipped: ssid or url empty` | 启用 upload_enabled；填写完整 WiFi 信息 |
| SD 卡满 | 容量管理失效 | 查日志 `cleanup` 频率；查 SD 卡剩余空间 | 检查清理逻辑（升级固件）；手动清理旧照片；换更大 SD 卡 |
| SD 卡满 | SD 卡损坏（误报满） | 万用表/电脑检测 SD 卡；查日志 | 更换 SD 卡 |
| SD 卡频繁损坏 | 非 High Endurance 卡 | 确认 SD 卡型号；查读写错误日志 | 更换为 SanDisk High Endurance 或工业级 SD 卡 |
| 配置丢失 | config.json 被覆盖 / SD 卡异常 | 查 SD 卡 config.json 内容；查日志 | 重新写入 config.json；更换 SD 卡 |

### 2.5 防护与环境类

| 现象 | 可能原因 | 排查步骤 | 解决方法 |
|------|----------|----------|----------|
| 外壳进水 | 密封失效 | 检查内部湿度/水珠；检查密封圈 | 更换硅胶密封圈；重新打密封胶；重新做 IP65 测试 |
| 外壳进水 | PG7 接头松动 | 检查接头紧固情况 | 拧紧 PG7 螺母；补密封胶 |
| 摄像头窗结露 | 内部湿气 / 干燥剂失效 | 检查玻璃内侧；检查干燥剂 | 更换硅胶干燥剂；检查密封 |
| 外壳发黄 / 脆化 | UV 老化 | 检查外壳外观 | 更换外壳（选 ASA 材质更耐 UV） |
| 太阳能板发电下降 | 面板脏污 / 老化 | 万用表测输出电压/电流；查面板清洁度 | 清洁面板；更换老化面板（PET 封装 2~3 年需换） |

## 3. 硬件诊断方法

### 3.1 万用表测量

| 测量点 | 正常值 | 异常含义 | 操作 |
|--------|--------|----------|------|
| 电池正负极电压 | 3.0 ~ 3.65V（LiFePO4） | < 3.0V 过放；> 3.65V 过充 | 充电 / 检查充电 IC |
| 太阳能板输出（晴天） | 5 ~ 6V（开路） | < 4V 遮挡/损坏 | 清洁面板 / 更换 |
| 太阳能板充电电流（晴天） | 0.3 ~ 1A | 0A 未充电 | 检查 CN3791 / 接线 |
| 3.3V 供电（HT7333 输出） | 3.3V ± 0.1V | 偏差大则 LDO 损坏或负载过重 | 更换 HT7333 / 检查负载 |
| CR2032 电压 | 2.8 ~ 3.0V | < 2.5V 需更换 | 更换 CR2032 |
| 摄像头电源（CAM_EN=LOW 时） | 3.3V | 0V 则 MOSFET Q1 损坏 | 更换 AO3401 Q1 |
| SD 卡电源（SD_EN=LOW 时） | 3.3V | 0V 则 MOSFET Q2 损坏 | 更换 AO3401 Q2 |

### 3.2 串口日志查看

1. USB 连接设备与电脑。
2. 启动监控：`idf.py -p /dev/ttyACM0 monitor`（波特率 115200）。
3. 按 RST 键复位，观察完整启动日志。
4. 根据日志中的 `[ERROR]` / `[WARN]` 定位问题（参见第 1 节日志解读）。

> **现场无电脑时**：可仅靠 SD 卡日志排查。取卡后在电脑查看 `/sdcard/logs/YYYYMMDD.log`。

### 3.3 SD 卡日志导出

1. 断电后取出 SD 卡。
2. 用读卡器连接电脑。
3. 查看 `/sdcard/logs/` 目录：
   - `YYYYMMDD.log`：当日日志。
   - `YYYYMMDD_1.log`、`_2.log`：当日滚动日志。
4. 查看 `/sdcard/photos/YYYYMMDD/` 目录：照片文件，验证拍照功能。
5. 查看 `/sdcard/config.json`：确认当前配置。

> **导出后建议**：保留日志副本用于趋势分析（如电池电压长期变化）。

### 3.4 配置门户状态查询

无需串口即可查看设备状态：

1. 长按配置按钮（GPIO0）5 秒进入配置门户。
2. 手机连接 WiFi 热点 `OutdoorCam-XXXX`（密码 `12345678`）。
3. 浏览器访问 `http://192.168.4.1/status`，返回 JSON：
   ```json
   {
     "battery_v": 3.28,
     "battery_pct": 85,
     "sd_free_mb": 14326,
     "config": {
       "interval_minutes": 30,
       "resolution": "1600x1200",
       "quality": 10,
       "upload_enabled": false,
       "wifi_ssid": "",
       "server_url": ""
     }
   }
   ```
4. 通过 `battery_v` 判断电量，`sd_free_mb` 判断存储空间，`config` 确认配置。

### 3.5 I2C 总线诊断（DS3231）

若 RTC 异常，可通过串口日志判断 I2C 通信：
- `[rtc] init failed: ESP_ERR_TIMEOUT` → I2C 超时，检查 SDA(GPIO4)/SCL(GPIO5) 接线与 4.7kΩ 上拉。
- `[rtc] init failed: ESP_ERR_NOT_FOUND` → DS3231 未应答，检查地址（0x68）与供电。
- 时间读取返回全零 → CR2032 耗尽或 DS3231 损坏。

### 4.4 维护周期总览

| 周期 | 核心任务 | 预计耗时 |
|------|----------|----------|
| 每月 | 清洁、密封检查、照片抽查 | 15~30 分钟/台 |
| 每季 | 日志导出、电压分析、干燥剂更换 | 30~60 分钟/台 |
| 每年 | 换 CR2032、固件升级、密封圈更换 | 1~2 小时/台 |

## 5. 应急处理

### 5.1 设备无响应

**现象**：设备完全不工作，无拍照、无日志。

**处理步骤**：
1. **USB 连接看日志**：连接电脑 `idf.py monitor`，按 RST 复位，观察启动日志。
   - 若有日志 → 根据日志错误排查（多为 SD 卡 / 摄像头 / RTC 故障）。
   - 若无日志 → 电源问题或固件损坏。
2. **万用表测电池电压**：
   - 电压 < 2.5V → 电池过放，拆回充电。
   - 电压正常（3.0~3.65V）→ 进入下一步。
3. **按 RST 复位**：若复位后恢复 → 临时性死机，继续观察。
4. **重新烧录固件**：若仍无响应 → USB 烧录最新固件（按住 GPIO0 + RST 进入下载模式）。
5. **硬件排查**：若烧录后仍异常 → 检查 3.3V 供电、MCU 焊接，必要时返修。

### 5.2 数据丢失

**现象**：SD 卡无照片或照片缺失。

**处理步骤**：
1. **检查 SD 卡**：
   - SD 卡是否正确插入卡座。
   - 电脑读卡器能否识别，文件系统是否 FAT32。
   - `/sdcard/photos/` 与 `/sdcard/logs/` 目录是否存在文件。
2. **查日志定位**：导出 `/sdcard/logs/` 日志，查找 `storage` / `capture` ERROR 记录。
3. **WiFi 回传备份**（如启用）：登录服务器查看是否有上传记录，作为数据补充。
4. **更换 SD 卡**：若 SD 卡损坏（电脑无法读取 / 频繁报错），更换后重新部署。
5. **预防**：定期导出数据备份；使用 High Endurance SD 卡降低损坏风险。

### 5.3 电池耗尽

**现象**：日志显示低电压，设备停止拍照或无响应。

**处理步骤**：
1. **拆回充电**：取下电池用充电器充至 3.65V，或 USB 充电。
2. **检查太阳能充电系统**：
   - 万用表测太阳能板输出（晴天应 ≥ 5V）。
   - 测 CN3791 充电电流（应 > 0）。
   - 检查太阳能板是否被遮挡、脏污、损坏。
3. **检查电池健康度**：若充电后电压迅速下降 → 电池老化，更换 18650。
4. **调整配置降低功耗**：若充电不足以支撑当前频率 → 增大 `interval_minutes`，或关闭 `upload_enabled`。
5. **环境评估**：若连续阴雨导致充电不足 → 增大太阳能板功率或电池容量。

### 5.4 外壳进水

**现象**：内部出现水珠、湿度高、设备异常。

**处理步骤**：
1. **立即断电**：取下电池，避免短路损坏电路。
2. **干燥处理**：开盖自然晾干，或用吹风机冷风吹干（禁用热风）。
3. **检查进水点**：
   - 密封圈是否老化 / 卷边 / 未压紧。
   - PG7 接头是否松动。
   - 螺丝孔是否渗水。
   - 摄像头窗 O 圈是否失效。
4. **更换密封件**：更换硅胶密封圈，重新打密封胶，固化 24 小时。
5. **IP65 测试**：重新密封后做喷水测试确认无渗漏。
6. **功能验证**：确认设备干燥后上电测试，若元件已损坏则返修。
