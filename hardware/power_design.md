# 电源管理子系统设计 - 户外定时拍照系统

> 文档版本：v1.0
> 设计目标：太阳能供电 + LiFePO4 储能，满足户外连续阴雨 7 天以上独立运行，深度睡眠电流 < 1mA。

## 3. 充电控制器电路设计（CN3791）

### 3.1 CN3791 简介

CN3791 是一款支持 **MPPT（最大功率点跟踪）** 的同步降压型太阳能锂电池充电 IC，原生支持 LiFePO4 电池（3.65V 截止），适用于 5V 太阳能板 + 单节 LiFePO4 场景。

| 特性 | 参数 |
|------|------|
| 输入电压 | 4.5V ~ 28V |
| 充电电流 | 可编程，最高 4A（外接检流电阻） |
| 电池类型 | LiFePO4（3.65V 截止）/ 可选 Li-ion（4.2V） |
| MPPT | 支持，跟踪电压 = 0.75 × Voc（可调） |
| 转换效率 | 最高 95%（同步整流） |
| 封装 | SOP-8 |
| 温度监测 | TS 引脚接 NTC，低温/高温停止充电 |
| 状态指示 | STAT1/STAT2 双 LED 输出（充电中/充满/故障） |

### 3.3 MPPT 工作原理

太阳能板的输出功率随电压变化呈"钟形"曲线，存在一个**最大功率点（MPP）**。MPP 电压通常为开路电压 Voc 的 75~80%。

```
   功率 P
    │        ╱╲
    │       ╱  ╲  ← 最大功率点 MPP
    │      ╱    ╲     (Vmp ≈ 0.75 × Voc)
    │     ╱      ╲
    │    ╱        ╲
    │  ╱            ╲
    │╱                ╲
    └────────────────────── 电压 V
   0        Vmp        Voc=6V
              ↑
         CN3791 跟踪此点
```

**CN3791 MPPT 实现**：
1. CN3791 通过 MPPT 引脚的分压电阻设定跟踪电压比（默认 0.75×Voc）。
2. 当太阳能板电压被拉低到此值时，IC 认为达到 MPP，按此电压调整充电电流。
3. 弱光下太阳能板输出能力下降，CN3791 自动降低充电电流维持输入电压在 MPP，最大化能量采集。
4. 相比无 MPPT 的线性充电（如 TP4056 直连），**弱光场景发电量提升 20~30%**。

### 3.4 LiFePO4 充电曲线

```
  电池电压 V
   3.65 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┬───── CV 阶段（恒压 3.65V，电流渐降）
                                    │
   3.4 │                            │
       │                            │
   3.3 │           CC 阶段           │
       │        （恒流 1.2A）         │
   3.2 │────────────────────────────┤ ← 截止（电流 < C/10 = 120mA）
       │                            │
   3.0 │                            │  停止充电
       │                            │
   2.5 └────────────────────────────── 放电截止（建议 3.0V 停机）
       └────────────────────────────── 时间
```

| 充电阶段 | 电压 | 电流 | 说明 |
|----------|------|------|------|
| 涓流预充（<2.5V） | — | C/20 | 电池过放时小电流激活，本项目不深放可省 |
| 恒流（CC） | <3.65V | 1.2A（恒定） | 电池电压从 3.2V 升至 3.65V |
| 恒压（CV） | 3.65V | 渐降 | 电流降至 120mA（C/10）时截止 |
| 充满 | — | 0 | CN3791 停止充电，STAT2 拉低（绿灯亮） |
| 补充 | — | — | 电压降至 3.4V 以下重新触发充电 |

> **LiFePO4 无需浮充/涓流**（无记忆效应，过充有害），CN3791 充满即停，优于铅酸充电策略。

## 5. LDO 稳压设计（HT7333）

### 5.1 HT7333 选型

| 参数 | HT7333 | AMS1117-3.3（对比） |
|------|--------|---------------------|
| 输出电压 | 3.3V ±2% | 3.3V ±1% |
| 最大输出电流 | 250mA | 1000mA |
| **静态电流 Iq** | **4µA** | **5mA**（高 1000 倍） |
| Dropout | 90mV@10mA | 1.1V@1A |
| 封装 | SOT-89 | SOT-223 |

> **关键优势**：HT7333 的 Iq 仅 4µA，深度睡眠时几乎不耗电。若用 AMS1117，仅 LDO 静态电流就 5mA，深睡 24h 耗电 5×3.2×24 = 384mWh，**超过系统全部其他功耗**，完全无法满足户外长期运行。HT7333 是本项目低功耗设计的关键元件。

### 5.2 LDO 应用电路

```
   电池 3.2~3.65V                                  系统 3.3V
       ───┬────────────────────┐                  ┌──────────────┬─── 3V3
          │                    │                  │              │
         ┌┴┐ C2 输入          │ VIN    VOUT ┌────┴┐            ┌┴┐ C1 储能
         │ │ 22µF              │   HT7333    │     │            │ │ 470µF
         └┬┘                   │   GND  GND  │     │            └┬┘
          │                    │             │     │             │
          │                    └──────┬──┬───┘     │             │
          │                           │  │         │             │
          │                          GND ─────────┴─ GND         │
          │                                                      │
         ─┴─ GND                                                ─┴─ GND
```

| 元件 | 参数 | 作用 |
|------|------|------|
| C2（输入电容） | 22µF 10V X5R | LDO 输入稳定，吸收电池端纹波 |
| C1（输出储能电容） | **470µF 6.3V 低 ESR 聚合物** | **关键**：缓冲拍照瞬间 250mA 峰值电流（HT7333 仅 250mA 标称，峰值靠电容供给） |
| C3（输出滤波） | 100nF X7R 0603 | 高频去耦，靠近 LDO 输出 |
| C5（各 IC 去耦） | 100nF × 6 | 每个 IC 电源引脚就近放置 |

### 5.3 峰值电流处理

ESP32-S3 + OV2640 拍照瞬间峰值电流可达 350mA，而 HT7333 标称仅 250mA。处理策略：

1. **470µF 大电容缓冲**：拍照 5s 期间，超出的 100mA 由 C1 放电供给。
   - 电压跌落：ΔV = I×t/C = 0.1A × 5s / 0.00047F = 1.06V（理论）
   - 实际因电池也持续供电，跌落远小于此值（实测约 50~100mV）。
2. **预热策略**：固件在拍照前 200ms 上电摄像头，让电容预充电，避免同时启动冲击。
3. **降频策略**：CPU 可在拍照时降至 160MHz，降低瞬时功耗。
4. **备用方案**：若实测电压跌落过大，可改用 ME6211C33（500mA，Iq 1µA）替代 HT7333。

### 5.4 LDO 效率

LDO 为线性稳压，效率 = Vout / Vin：

| 电池电压 | LDO 效率 | 说明 |
|----------|----------|------|
| 3.65V（满电） | 3.3/3.65 = 90.4% | 正常 |
| 3.2V（标称） | 3.3/3.2 = 103% ⚠ | 实际输出 ≈ 3.11V（dropout 限制），ESP32 可工作至 3.0V |
| 3.0V（低电） | 输出 ≈ 2.91V | ESP32 仍可工作，但建议停机保护 |

> **LiFePO4 电压平台稳定**：3.2~3.3V 占放电区间 80%，此期间 LDO 输出略低于 3.3V 但 ESP32-S3（2.7~3.6V）与 OV2640（2.6~3.0V DVDD）均可正常工作。LDO 方案在本项目优于 DC-DC（DC-DC 静态电流 5~50µA，且纹波干扰 ADC）。

## 6. 受控电源开关电路（AO3401 MOSFET）

### 6.1 设计目标

摄像头与 SD 卡在深度睡眠时必须**完全断电**（OV2640 待机 ~10mA，SD 卡待机 ~0.5mA，累计会击穿 0.5mA 睡眠预算）。通过 P-MOSFET 高边开关实现受控上电。

### 6.2 单路 MOSFET 开关电路

```
                          3V3 主电源（HT7333 输出）
                              │
                              │  源极 S
                          ┌───┴───┐
                          │       │
                          │ AO3401│  P-MOS
                          │ Q1    │
                          │       │
                          └───┬───┘
                              │  漏极 D
                              ├──────────→ 摄像头 3V3（受控）
                              │
                              │  栅极 G
                  ┌───────────┤
                  │           │
                 ┌┴┐ Rpull   │
                 │ │ 10kΩ    │
                 │ │ 上拉    │
                 └┬┘         │
                  │     ┌────┴────┐
                  │     │  Rgate  │
                  │     │  100Ω   │
                  │     └────┬────┘
                  │          │
                  ├─── 3V3   │  ← 默认上拉，MOSFET 关断
                  │          │
                  │      ┌───┴───┐
                  │      │ GPIO  │  GPIO_CAM_EN (GPIO 2)
                  │      │ 输出   │
                  │      └───┬───┘
                  │          │
                 ─┴─ GND    ─┴─ GND

   逻辑：
   GPIO = HIGH (3.3V) → Vgs = 0V  → MOSFET 关断 → 摄像头断电
   GPIO = LOW  (0V)   → Vgs = -3.3V → MOSFET 导通 → 摄像头上电
```

### 6.3 工作逻辑表

| GPIO 状态 | Vgs | MOSFET 状态 | 摄像头/SD 电源 | 系统状态 |
|-----------|-----|-------------|----------------|----------|
| HIGH（3.3V） | 0V | 关断 | 0V（断电） | 深度睡眠/默认 |
| LOW（0V） | -3.3V | 导通 | 3.3V（上电） | 拍照工作 |

> **上拉电阻关键作用**：ESP32 复位/上电瞬间 GPIO 为高阻态，若无上拉，栅极悬空可能导致 MOSFET 误导通，摄像头意外通电消耗电量。10kΩ 上拉确保复位期间 MOSFET 默认关断。

### 6.4 元件参数

| 元件 | 参数 | 作用 |
|------|------|------|
| Q1 / Q2 | AO3401，P-MOS，-30V/-4A，Rds(on)=36mΩ@Vgs=-4.5V | 高边开关 |
| Rpull（R3/R4） | 10kΩ 5% 0805 | 栅极上拉到源极，默认关断 |
| Rgate | 100Ω 5% 0603 | 栅极串联电阻，抑制开关瞬间振铃 |

### 6.5 导通压降验证

| 参数 | 计算 | 结果 |
|------|------|------|
| 工作电流 | 摄像头+SD 峰值 250mA | — |
| Rds(on) | 36mΩ（Vgs=-4.5V），Vgs=-3.3V 时略大约 50mΩ | — |
| 导通压降 | V = I × Rds(on) = 0.25 × 0.05 | **12.5mV** |
| 摄像头端电压 | 3.3V - 12.5mV | **3.287V** ✅ |

> 压降可忽略，AO3401 选型合理。

### 6.6 两路 MOSFET 分配

| MOSFET | 控制对象 | GPIO | 上电时序 |
|--------|----------|------|----------|
| Q1 | OV2640 摄像头电源 | GPIO 2（CAM_EN） | 拍照前 200ms 上电预热 |
| Q2 | MicroSD 卡电源 | GPIO 42（SD_EN） | 拍照前 100ms 上电 |

### 6.7 上电/断电时序

```
时间轴 ──────────────────────────────────────────────────────▶
                              ┌─── 摄像头工作 5s ───┐
                              │                      │
GPIO_SD_EN:  ────────┐        ┌────────────────┐    ┌────────
                   └──┘ 100ms  │                │    │
                              │                │    │
GPIO_CAM_EN: ──────────┐      │  ┌──200ms──┐  │    │
                       └──────┘  │         │  └────┘
                                 │         │
摄像头电源:   0V ────────────────┘ 3.3V ────┘ 0V ────────
                                 │         │
                                 └─ 预热 ──┴─ 拍照+SD写入 ─┘
```

## 7. 电池电压采样电路

### 7.1 电路设计

```
   电池 VBAT (0~3.65V)
       ───┬─────────────────┐
          │                 │
         ┌┴┐ R1 100kΩ 1%   │  ← 高阻值降低静态电流
         │ │               │
         └┬┘               │
          │                 │
          ├───→ ADC1_CH0   │  ← 分压点，V_sense = VBAT / 2
          │  (GPIO 1)       │
         ┌┴┐ R2 100kΩ 1%   │
         │ │               │
         └┬┘               │
          │                 │
         ─┴─ GND          ─┴─ GND

   并联 C_filter 100nF（在 ADC 引脚与 GND 之间，滤除高频噪声）
```

### 7.2 元件参数

| 元件 | 参数 | 作用 |
|------|------|------|
| R1 | 100kΩ 1% 0805 | 上分压电阻 |
| R2 | 100kΩ 1% 0805 | 下分压电阻 |
| C_filter | 100nF X7R 0603 | ADC 采样滤波，并联在 R2 两端 |

### 7.3 采样电压计算公式

分压比 = R2 / (R1 + R2) = 100k / (100k + 100k) = **1/2**

$$V_{sense} = V_{BAT} \times \frac{R_2}{R_1 + R_2} = \frac{V_{BAT}}{2}$$

$$V_{BAT} = V_{sense} \times 2$$

ESP32-S3 ADC 为 12-bit（0~4095），参考电压 3.3V（衰减 11dB 可测至 ~3.1V，需校准）：

$$V_{sense} = \frac{ADC\_value}{4095} \times 3.3V$$

$$\boxed{V_{BAT} = \frac{ADC\_value}{4095} \times 3.3V \times 2 = \frac{ADC\_value \times 6.6}{4095}}$$

#### 各电量点 ADC 读数（理论值，需实测校准）

| 电池状态 | VBAT | V_sense | ADC 值（12-bit） |
|----------|------|---------|------------------|
| 满电 | 3.65V | 1.825V | 2263 |
| 标称 | 3.2V | 1.6V | 1984 |
| 低电告警 | 3.0V | 1.5V | 1861 |
| 停机保护 | 2.8V | 1.4V | 1736 |

> **注意**：ESP32-S3 ADC 非线性较大，需做多点校准（factory calibration）。建议固件用 `esp_adc_cal` 库 + eFuse 校准数据，或自标定查表。

### 7.4 静态电流影响

分压网络静态电流 = VBAT / (R1+R2) = 3.2V / 200kΩ = **16µA**

- 全天 24h 耗电：16µA × 3.2V × 24h = 1.23 mWh/天（占日预算 0.6%，可接受）
- 若需进一步降低，可用 1MΩ/1MΩ 分压（静态 1.6µA），但 ADC 内阻增大影响精度，需加运放跟随器（增加成本）。本项目 100kΩ 为平衡选择。

### 7.5 低电量保护策略

| 电压 | 系统动作 | 说明 |
|------|----------|------|
| > 3.4V | 正常拍照 | 电量充足 |
| 3.0~3.4V | 正常拍照，日志告警 | 低电量预警 |
| 2.8~3.0V | **拍照间隔翻倍**（48→24 次/天） | 降低功耗延长运行 |
| < 2.8V | **停止拍照，仅维持 RTC + 深睡** | 保护电池，等待太阳能回充 |
| < 2.5V | 硬件保护板断开（若有） | 防止过放损坏 |

## 9. 电源完整性设计要点

1. **PCB 布局**：太阳能板输入 → CN3791 → 电池 → LDO 走线短而宽，减小压降。
2. **大电流回路**：CN3791 电感回路面积最小化，避免 EMI。
3. **模拟/数字地分割**：ADC 采样（GPIO 1）下方地平面独立，单点接数字地。
4. **去耦电容**：每个 IC 电源引脚 100nF + 10µF，LDO 输入输出 22µF，主电源 470µF。
5. **电池走线**：电池正负极走线短，串联温度保险丝（可选）。
6. **太阳能接口防反接**：输入串联肖特基二极管（SS34）或 P-MOS 防反接电路。
7. **ESD 保护**：太阳能板接线端、USB 接口加 TVS 二极管。
8. **测试点**：VBAT、3V3、GND 预留测试点，便于调试与功耗测量。
