# 外壳与防护设计 - 户外定时拍照系统

> 文档版本：v1.0
> 设计目标：满足户外长期（数月~数年）无人值守运行的 IP65 防护、UV 抗老化、宽温散热与可靠安装。

## 1. 外壳材料选型

### 1.1 材料对比与选型

| 材料 | 优势 | 劣势 | 适用性 |
|------|------|------|--------|
| **ABS+PC 合金** | 阻燃 UL94V-0、抗冲击、UV 稳定剂可加、易注塑、成本低 | 长期 UV 仍会轻微老化 | ✅ **本项目首选** |
| 纯 ABS | 成本低、易加工 | 阻燃差、UV 老化快（2~3 年发脆） | ❌ 户外长期不推荐 |
| 纯 PC（聚碳酸酯） | 高抗冲、耐温好、透明 | 易应力开裂、成本高 | 适合开窗部分 |
| PA66+GF（尼龙玻纤） | 高强度、耐高温 | 吸水率高、成本高 | 过度设计 |
| 铝合金压铸 | 散热极佳、坚固 | 屏蔽 Wi-Fi、成本高、重 | 需外接天线时可用 |
| ASA | 抗 UV 极佳（10 年以上） | 成本高、供应商少 | 高端可选 |

### 1.2 选型结论

**外壳主体：ABS+PC 合金（如 Bayer Bayblend FR3010 或等效），添加 UV 稳定剂**
- 阻燃等级：UL94V-0（户外电气安全要求）
- 颜色：白色或浅灰（反射阳光，降低外壳温升）
- 厚度：壁厚 2.0~2.5mm，四角加强筋 3mm
- UV 稳定剂：Tinuvin 770 或等效，户外寿命 ≥ 5 年

### 1.3 外壳尺寸与结构

| 参数 | 规格 |
|------|------|
| 外形尺寸 | 120 × 80 × 55 mm（长×宽×高） |
| 壁厚 | 2.0mm（主体），3.0mm（四角加强筋） |
| 内部可用 | 114 × 74 × 49 mm |
| 重量 | 约 80g（空壳） |
| 开口 | 摄像头窗 1 个、太阳能板接线孔 2 个、按键孔 1 个、天线孔（可选）1 个 |
| 固定 | PCB 4×M2 铜柱，外壳 4×壁挂耳 + 1×三脚架 1/4 螺纹 |

## 2. 防护等级 IP65 实现方案

IP65 含义：**完全防尘（IP6x）+ 防各角度低压喷水（IPx5）**，不防长期浸水。

### 2.1 IP65 密封方案总览

```
   ┌─────────────────────────────────────────┐
   │              上盖（带密封圈槽）            │  ← 硅胶密封圈预压 20%
   │  ┌─────────┐                ┌────────┐  │
   │  │ 摄像头窗 │  ┌──────┐    │ 按键帽  │  │
   │  │（O圈+玻璃）│  │ 天线 │    │（硅胶） │  │
   │  └─────────┘  └──────┘    └────────┘  │
   │           PG7 电缆接头 × 2              │
   └─────────────────────────────────────────┘
                      ↓ 上下盖合拢，螺丝锁紧
   ┌─────────────────────────────────────────┐
   │              下盖（主体）                  │
   │  ┌─────────────────────────────────┐    │
   │  │  PCB（4×M2 铜柱固定）              │    │
   │  │  ┌─────┐  ┌─────┐  ┌─────┐      │    │
   │  │  │ESP32│  │RTC  │  │电池  │      │    │
   │  │  └─────┘  └─────┘  └─────┘      │    │
   │  └─────────────────────────────────┘    │
   │  壁挂耳 × 4    1/4 三脚架螺纹 × 1        │
   └─────────────────────────────────────────┘
```

### 2.2 各开口密封方案

| 开口 | 密封方式 | 防护等级 |
|------|----------|----------|
| 上下盖合缝 | 硅胶 O 形密封圈（预压 20%） | IP65 |
| 摄像头窗 | 光学玻璃 + 硅胶 O 圈压紧 | IP65 |
| 太阳能板电缆 | PG7 尼龙防水接头（含氯丁橡胶密封） | IP68 |
| 配置按键 | 硅胶按键帽（过盈配合 + 裙边） | IP65 |
| 天线（可选） | IPEX 穿墙馈通 + 硅胶密封 | IP65 |
| 螺丝孔 | 沉头螺丝 + 硅胶垫片 | IP65 |

### 2.3 密封圈设计

| 参数 | 规格 |
|------|------|
| 材料 | 硅胶（VMQ），硬度 30~40 Shore A |
| 截面形状 | 圆形 O 圈，直径 Φ2.0mm |
| 压缩比 | 20~25%（IP65 推荐） |
| 工作温度 | -40~+150℃（户外宽温） |
| 老化寿命 | ≥ 10 年（硅胶耐 UV） |
| 槽型 | 矩形槽，宽 2.5mm，深 1.6mm |
| 槽面粗糙度 | Ra ≤ 1.6µm（光洁面，避免微漏） |

## 3. 摄像头开窗设计

### 3.1 开窗结构

```
        外壳外表面
            │
   ┌────────┴────────┐
   │  AR 镀膜光学玻璃  │  ← 厚度 1.0mm，方形 12×12mm
   │                 │
   │  ┌───────────┐  │
   │  │ 硅胶 O 圈  │  │  ← 内圈密封，Φ10mm×Φ1.5mm
   │  └───────────┘  │
   │                 │
   │  防雾涂层        │  ← 玻璃内侧涂亲水防雾膜
   │                 │
   └────────┬────────┘
            │
            │  压圈（螺纹或卡扣锁紧）
            │
        ┌───┴───┐
        │OV2640 │  ← 镜头距玻璃 2~3mm
        │ 模组   │
        └───────┘
```

### 3.2 光学玻璃规格

| 参数 | 规格 | 说明 |
|------|------|------|
| 材质 | 高透硼硅玻璃（K9 或 BK7） | 透光率 > 92% |
| 厚度 | 1.0mm | 减少光学畸变 |
| 尺寸 | 12×12mm 方形 | 匹配 OV2640 视场角 |
| 镀膜 | **AR 增透膜**（单层 MgF2） | 透光率提升至 ≥ 97%，减少眩光 |
| 钢化 | 化学钢化（可选） | 抗冲击，防石子飞溅 |
| 工作温度 | -40~+120℃ | 户外宽温 |

### 3.3 防雾设计

户外日夜温差大，玻璃内侧易结露导致拍照模糊。防雾措施：

| 措施 | 实现 | 效果 |
|------|------|------|
| 亲水防雾涂层 | 玻璃内侧涂二氧化硅亲水膜 | 水汽铺展成透明膜，不凝成水珠 |
| 干燥剂 | 外壳内放 1g 硅胶干燥剂包 | 吸收内部湿气，3~6 个月更换 |
| 密封防潮 | IP65 密封隔绝外部湿气 | 减少水汽进入 |
| 电路自热 | 拍照前 MCU 工作 1s，轻微加热空气 | 间接防雾（效果有限） |
| 可选加热片 | 贴 0508 PTC 加热片于玻璃边 | 主动除雾，需额外 200mW 功耗 |

### 3.4 O 圈密封

| 参数 | 规格 |
|------|------|
| 材料 | 硅胶 O 圈，Φ10mm 内径×Φ1.5mm 线径 |
| 压缩比 | 25% |
| 安装 | 玻璃与外壳之间，压圈锁紧 |

## 5. 散热设计

### 5.1 热源分析

| 元件 | 功耗 | 工作时长 | 温升风险 |
|------|------|----------|----------|
| ESP32-S3（拍照时） | 250mA × 3.3V ≈ 0.8W | 5s/次，48 次/天 | 低（短时） |
| ESP32-S3（Wi-Fi 回传） | 170mA × 3.3V ≈ 0.56W | 10s/次，24 次/天 | 低（短时） |
| OV2640 | 100mA × 3.3V ≈ 0.33W | 5s/次 | 低 |
| CN3791（充电时） | 转换损耗 ~0.25W（5W×5%） | 连续数小时 | **中**（晴天持续） |
| 太阳能板 | — | — | 板面温度可达 60~70℃ |

### 5.2 散热策略

#### 5.2.1 MCU 远离阳光直射面

```
   太阳光 ▼▼▼
   ┌─────────────────┐
   │ 太阳能板（受热）  │  ← 顶部受阳光直射，温度高
   ├─────────────────┤
   │  空气层（隔热）   │  ← 5mm 空气间隙，隔热
   │                 │
   │  ┌───────────┐  │
   │  │ PCB       │  │  ← PCB 倒置，MCU 朝下（背光面）
   │  │ [MCU朝下] │  │
   │  └───────────┘  │
   │                 │
   │  下盖（背光面）   │  ← 温度较低
   └─────────────────┘
```

- **MCU 布置在 PCB 朝下一面**，避免阳光直射的太阳能板侧。
- PCB 与太阳能板之间留 5mm 空气层，空气是良好的隔热介质。

#### 5.2.2 导热路径

| 元件 | 导热路径 | 实现 |
|------|----------|------|
| ESP32-S3 | 芯片 → PCB 铜箔 → 外壳下盖 | 导热硅脂填充芯片与外壳间隙 |
| CN3791 | IC → PCB 铜箔 → 外壳侧壁 | 充电 IC 靠近外壳侧壁，散热焊盘连大面积铜 |
| 太阳能板 | 板背面 → 空气 | 板与外壳间留空气层，不直接导热到内部 |

#### 5.2.3 通风口（防结露型）

```
   外壳下部开迷宫式通风口：
   
   外壁    内壁
    │       │
    │ ┌───┐ │  ← 迷宫式风道，防雨水直入
    │ │   │ │
    │ │   └─┤
    │ │     │
    │ └─────┘
    │
   水滴沿外壁流下，空气可流通
```

- **目的**：平衡内外气压，避免温度变化导致密封圈"呼吸"吸入湿气。
- **结构**：迷宫式风道（IPX4 防溅水），不开直通孔。
- **位置**：外壳底部（雨水不到的背光面）。
- **数量**：2 个（1 进 1 出，形成对流）。
- **注意**：通风口会降低 IP65 等级至 IP54，若需严格 IP65 则不开通风口，靠干燥剂防潮。

### 5.3 导热硅脂规格

| 参数 | 规格 |
|------|------|
| 型号 | 信越 7762 或 Dow Corning TC-5121 |
| 导热系数 | ≥ 1.0 W/m·K |
| 工作温度 | -40~+150℃ |
| 用量 | ESP32 模组金属屏蔽罩顶部薄涂一层，接触外壳下盖 |
| 寿命 | ≥ 5 年不干涸 |

## 6. 温度应对设计

### 6.1 宽温元器件选型

| 元件 | 工作温度 | 备注 |
|------|----------|------|
| ESP32-S3-WROOM-1 | -40~+85℃ | 模组级宽温 |
| OV2640 | -30~+70℃ | 摄像头模组 |
| DS3231SN | -40~+85℃ | RTC 宽温 |
| CN3791 | -40~+85℃ | 充电 IC |
| LiFePO4 18650 | 放电 -20~+60℃，充电 -10~+45℃ | 电池（受限最大） |
| MicroSD（工业级） | -25~+85℃ | 推荐 SanDisk Industrial |
| 外壳 ABS+PC | -40~+85℃ | 主体材料 |

### 6.2 高温应对（>+60℃）

| 措施 | 实现 |
|------|------|
| 白色外壳 | 反射阳光，外壳温升降低 10~15℃ |
| MCU 背光布置 | 避开太阳能板热源 |
| 导热硅脂到外壳 | 利用外壳大面积散热 |
| 通风口对流 | 迷宫式风道（可选） |
| 软件降频 | >70℃ 时 CPU 降频至 160MHz，降低发热 |
| 高温停机保护 | >80℃ 暂停拍照，仅维持深睡，温度恢复后重启 |

### 6.3 低温应对（<-10℃）

| 措施 | 实现 | 说明 |
|------|------|------|
| 宽温元器件 | 全部选 -20℃ 以上规格 | 见上表 |
| LiFePO4 低温充电限制 | CN3791 TS + NTC，<0℃ 停止充电 | 防止锂枝晶 |
| LiFePO4 低温放电 | -20℃ 仍可放电（容量降至 70%） | 可维持运行 |
| 电池保温 | 电池外包 5mm EVA 泡棉 | 缓冲温度骤变 |
| **可选加热片** | 0508 PTC 自限温加热片（5V 0.5W）+ MOSFET 受控 | <-5℃ 时启动，使电池可充电 |
| 软件低温保护 | <-20℃ 暂停拍照，仅维持 RTC | 防止 LCD_CAM 异常 |

### 6.4 可选低温加热片设计

```
   低温加热片电路（可选）：

   3V3 ──┬──────────────────────┐
         │                      │
         │                  ┌───┴───┐
         │                  │ PTC   │ 5V 0.5W 自限温 50℃
         │                  │ 加热片 │
         │                  └───┬───┘
         │                      │
         │              ┌───────┴───────┐
         │              │  AO3401 Q3    │  受控开关
         │              └───────┬───────┘
         │                      │
         │                   ┌──┴──┐
         │                   │10kΩ │ 上拉
         │                   └──┬──┘
         │                      │
         │              ┌───────┴───────┐
         │              │ GPIO_HEATER   │  GPIO 47 或 48
         │              │ (温度<-5℃时LOW)│
         │              └───────────────┘
         │
        ─┴─ GND

   逻辑：温度传感器（DS3231 自带或外接 SHT30）<-5℃ 时 GPIO 拉低，加热片上电，
        PTC 自限温至 50℃，电池温度回升后可正常充电。
   功耗：0.5W，仅低温启动，对日能耗影响可控。
```

> **注意**：加热片仅在高寒地区（<-10℃）部署时启用，温带/热带气候无需此电路。

## 7. 安装方式

### 7.1 三种安装方式对比

| 方式 | 适用场景 | 优势 | 劣势 |
|------|----------|------|------|
| **抱箍安装** | 树干、电线杆、管道 | 快速、通用、可拆卸 | 需匹配杆径 |
| **壁挂安装** | 墙壁、立柱侧面 | 稳固、防盗 | 需打孔 |
| **三脚架安装** | 地面、临时部署 | 灵活、可移动 | 易被盗、需配重 |

## 11. 装配工艺要点

1. **密封圈装配**：O 圈放入槽内后涂少量硅油润滑，避免合盖时卷边。
2. **玻璃安装**：玻璃两侧各放一片 O 圈，压圈旋入压紧至 O 圈压缩 25%。
3. **电缆接头**：穿入电缆后拧紧螺母至手拧不动+1/4 圈，橡胶芯抱紧电缆。
4. **太阳能板嵌入**：板放入凹槽后，边缘溢胶密封，硅胶固化 24h 后方可户外使用。
5. **PCB 固定**：4×M2 铜柱 + 不锈钢螺丝，MCU 涂导热硅脂接触外壳下盖。
6. **干燥剂放置**：1g 硅胶包用胶带贴在外壳内壁非热源区。
7. **螺丝锁紧**：上下盖螺丝对角线顺序锁紧，扭矩 0.2~0.3 N·m，确保密封圈均匀受压。
8. **测试**：装配完成后做 IP65 喷水测试，确认无渗漏后方可部署。
