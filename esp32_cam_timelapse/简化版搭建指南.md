## 程序配置

### 需要修改的配置

```cpp
// 文件: esp32_cam_outdoor_simple.ino

// 1. WiFi配置（第24-25行）- 必须修改
const char* ssid = "你的WiFi名称";
const char* password = "你的WiFi密码";

// 2. 拍照间隔（第29行）- 根据需要修改
const unsigned long CAPTURE_INTERVAL = 60000;  // 60秒
const uint64_t DEEP_SLEEP_TIME_US = 60 * 1000000ULL;  // 深度睡眠60秒

// 3. 夜视光线阈值（第34行）- 根据环境调整
const int LIGHT_THRESHOLD = 500;  // ADC值低于此开启夜视
```

## 功耗分析

### 工作功耗

| 阶段 | 电流 | 时间 |
|------|------|------|
| 唤醒+初始化 | 150mA | 2秒 |
| WiFi连接 | 80mA | 5秒 |
| 拍照 | 180mA | 1秒 |
| SD卡写入 | 120mA | 2秒 |
| **总计** | - | **~10秒** |

### 睡眠功耗

| 模式 | 电流 | 说明 |
|------|------|------|
| 深度睡眠 | 10μA | 主要模式 |
| 浅睡眠 | 5mA | 不推荐 |

### 续航计算

**电池**: 2×3000mAh = 6000mAh

| 拍照间隔 | 平均电流 | 理论续航 |
|----------|----------|----------|
| 30秒 | 50mA | 5天 |
| 1分钟 | 30mA | 8天 |
| 5分钟 | 15mA | 16天 |
| 10分钟 | 12mA | 20天 |

**加上5W太阳能板（每天补充4000mAh）**:
- 理论可实现 **无限续航**（阳光充足时）

## 防水处理

### 必需防水位置

1. **外壳缝隙** - 盖子边缘涂硅酮胶
2. **太阳能板线缆入口** - PG7防水接头
3. **摄像头位置** - 透明亚克力面板 + 密封胶

### 摄像头防水罩制作

```
材料：
- 透明亚克力板 (3mm厚)
- 硅酮密封胶
- 热熔胶

步骤：
1. 在防水盒盖上开直径20mm圆孔
2. 裁剪亚克力板覆盖整个盖子内侧
3. 摄像头对准圆孔，用密封胶固定
4. 24小时固化后测试防水
```

## 安装建议

### 位置选择

| 因素 | 要求 |
|------|------|
| **阳光** | 每天≥4小时直射 |
| **朝向** | 太阳能板朝正南 |
| **倾角** | 纬度角度（例：北京40°） |
| **WiFi** | 信号强度≥-70dBm |
| **防护** | 避免雨淋直接冲刷 |

### 角度计算

```
最佳太阳能板倾角 = 当地纬度

例如：
- 北京 (40°N) → 40°
- 上海 (31°N) → 31°
- 广州 (23°N) → 23°
```

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 不拍照 | 电池没电/SD卡问题 | 检查太阳能/换SD卡 |
| 夜间照片全黑 | 光线太暗 | 添加红外补光灯 |
| WiFi断开 | 信号不稳定 | 调整位置/加天线 |
| 外壳进水 | 密封失效 | 重新密封/换外壳 |
