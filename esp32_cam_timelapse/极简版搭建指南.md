
### 电池分压电路（电量监测）

```
电池正极 ──┬─── 100KΩ ──┬─── ESP32-CAM GPIO34
           │            │
           │         100KΩ
           │            │
           └────────────┴─── GND
```

### 说明

- 两个100K电阻组成分压电路，把最高8.4V降为4.2V
- ESP32-CAM通过ADC读取电压计算电量

## 功耗分析

### 工作功耗

| 阶段 | 电流 | 时间 |
|------|------|------|
| 唤醒+初始化 | 120mA | 1.5秒 |
| WiFi连接 | 80mA | 5秒 |
| 拍照 | 160mA | 1秒 |
| SD卡写入 | 100mA | 1.5秒 |
| **总计** | - | **~9秒** |

### 睡眠功耗

| 模式 | 电流 | 说明 |
|------|------|------|
| 深度睡眠 | 10μA | 主要模式 |

### 续航计算

**电池**: 2×3000mAh = 6000mAh

| 拍照间隔 | 平均电流 | 理论续航 |
|----------|----------|----------|
| 30秒 | 45mA | 5.5天 |
| 1分钟 | 25mA | 10天 |
| 5分钟 | 10mA | 25天 |
| 10分钟 | 8mA | 31天 |

**加上5W太阳能板（每天补充4000mAh）**:
- 阳光充足时，可实现**无限续航**

## 防水处理

### 必需防水位置

1. **外壳缝隙** - 盖子边缘涂硅酮胶
2. **太阳能板线缆入口** - PG7防水接头
3. **摄像头位置** - 透明亚克力面板 + 密封胶

### 摄像头防水罩制作

```
材料：
- 透明亚克力板 (3mm厚)
- 硅酮密封胶
- 热熔胶

步骤：
1. 在防水盒盖上开直径20mm圆孔
2. 裁剪亚克力板覆盖整个盖子内侧
3. 摄像头对准圆孔，用密封胶固定
4. 24小时固化后测试防水
```

## 安装建议

### 位置选择

| 因素 | 要求 |
|------|------|
| **阳光** | 每天≥4小时直射 |
| **朝向** | 太阳能板朝正南 |
| **倾角** | 纬度角度（例：北京40°） |
| **WiFi** | 信号强度≥-70dBm |
| **防护** | 避免雨淋直接冲刷 |

### 角度计算

```
最佳太阳能板倾角 = 当地纬度

例如：
- 北京 (40°N) → 40°
- 上海 (31°N) → 31°
- 广州 (23°N) → 23°
```

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 不拍照 | 电池没电/SD卡问题 | 检查太阳能/换SD卡 |
| WiFi断开 | 信号不稳定 | 调整位置/加天线 |
| 外壳进水 | 密封失效 | 重新密封/换外壳 |
| 电量下降快 | 太阳能板没对准 | 调整朝向和角度 |

## Arduino IDE 配置

### 安装ESP32开发板

1. 打开 Arduino IDE
2. 文件 → 首选项
3. 附加开发板管理器网址添加：
   ```
   https://dl.espressif.com/dl/package_esp32_index.json
   ```
4. 工具 → 开发板 → 开发板管理器
5. 搜索 "ESP32" 并安装

### 选择配置

```
工具 → 开发板: "ESP32 Wrover Module"
工具 → Flash Mode: "QIO"
工具 → Flash Size: "4MB (32Mb)"
工具 → Partition Scheme: "Huge APP (3MB No OTA/1MB SPIFFS)"
工具 → Upload Speed: "115200"
工具 → Port: 选择你的COM口
```

### 烧录程序

1. 连接USB-TTL（GPIO0接地进入下载模式）
2. 点击上传按钮
3. 看到 "Connecting..." 时按一下ESP32-CAM的复位键
4. 上传完成后断开GPIO0，再按复位键运行
