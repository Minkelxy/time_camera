### 工作模式

| 模式 | 说明 | 功耗 | 适用场景 |
|------|------|------|---------|
| **深度睡眠** | 定时唤醒拍照 | ~10μA | 长时间无人值守 |
| **PIR触发** | 检测到人/动物才拍照 | ~15mA | 安防监控 |
| **混合模式** | 定时 + PIR双重触发 | ~20mA | 野生动物观测 |

### 功耗分析

| 工作阶段 | 电流 | 时间 | 耗电 |
|----------|------|------|------|
| 深度睡眠 | 10μA | 99% | 极低 |
| WiFi连接 | 80mA | 10秒 | 中等 |
| 拍照 | 150mA | 3秒 | 较高 |
| SD卡写入 | 100mA | 2秒 | 中等 |
| **平均** | **~25mA** | - | - |

**电池续航计算**（6000mAh）：
- 理论续航 = 6000mAh / 25mA × 0.7（效率） = **168小时 ≈ 7天**

### 电池容量计算

**目标**：连续阴雨天 3-5天 持续工作

| 参数 | 数值 |
|------|------|
| 系统平均功耗 | 25mA |
| 每日耗电 | 25mA × 24h = 600mAh |
| 3天续航需求 | 600mAh × 3 = 1800mAh |
| 5天续航需求 | 600mAh × 5 = 3000mAh |
| **建议电池容量** | **6000mAh (2×3000mAh)** |

### 太阳能板选型

| 参数 | 5W (推荐) | 10W | 20W |
|------|----------|-----|-----|
| 充电电流 | ~800mA | ~1.6A | ~3.3A |
| 充满2Ah需要 | ~2.5小时 | ~1.3小时 | ~0.6小时 |
| 价格 | ¥20 | ¥35 | ¥60 |
| 适用场景 | 日常使用 | 高纬度/雨季 | 极寒/长期 |

**阳光充足地区的经验公式**：
- 5W太阳能板 ≈ 每天补充 4000-5000mAh（按4小时有效光照）
- 足够覆盖 ESP32-CAM 的日常消耗

### 电池保护

⚠️ **重要提醒**：

1. **必须使用带保护板的18650电池**，防止过充过放
2. **TP4056模块必须选择带保护板版本**
3. **添加自恢复保险丝**（500mA），防止短路
4. **添加防反接二极管**，防止电池反接损坏

## 外壳防水方案

### 推荐外壳

| 类型 | 规格 | 优点 | 缺点 |
|------|------|------|------|
| **塑料接线盒** | 158×90×60mm | 便宜，易加工 | 需额外防水处理 |
| **铝合金防水盒** | IP68级 | 防水性好，散热好 | 价格较高 |
| **PVC管道盒** | DIY | 成本低，可定制 | 需自行防水 |

### DIY防水方案（推荐）

**所需材料**：
- 透明塑料盒（收纳盒）
- 硅酮密封胶
- 防水胶带
- 热缩管

**制作步骤**：

1. **开孔**：
   - 摄像头位置：用开孔器开直径20mm圆孔
   - 太阳能板线：用开孔器开直径10mm圆孔
   - 预留散热孔（用透气膜覆盖）

2. **密封处理**：
   ```cpp
   // 密封顺序：
   1. 先在孔周围涂硅酮胶
   2. 放入线缆接头
   3. 再次涂胶密封
   4. 24小时固化
   ```

3. **缝隙处理**：
   - 盖子边缘：贴防水胶条
   - 螺丝孔：用热熔胶封住

### 摄像头防水罩

## 程序配置

### 基础配置（代码中修改）

```cpp
// WiFi配置 - 必须修改
const char* ssid = "你的WiFi名称";
const char* password = "你的WiFi密码";

// 拍照模式选择
const CaptureMode CAPTURE_MODE = MODE_HYBRID;
// MODE_INTERVAL    - 纯定时模式
// MODE_PIR_TRIGGER - PIR触发模式
// MODE_HYBRID     - 混合模式（推荐）

// 定时拍照间隔（毫秒）
const unsigned long CAPTURE_INTERVAL = 60000; // 60秒
const uint64_t DEEP_SLEEP_TIME_US = 60 * 1000000ULL; // 深度睡眠60秒

// 照片质量 (10-63, 越小越好)
const int JPEG_QUALITY = 12;

// 分辨率选择
const framesize_t FRAME_SIZE = FRAMESIZE_SVGA; // 800x600
// 可选: FRAMESIZE_VGA (640x480), FRAMESIZE_SVGA (800x600)
```

### 拍照模式详解

#### 1. 定时模式 (MODE_INTERVAL)
```cpp
适用场景：延时摄影、植物生长观察
配置示例：
  CAPTURE_INTERVAL = 300000;  // 5分钟拍一张
  DEEP_SLEEP_TIME_US = 300 * 1000000ULL; // 5分钟唤醒一次
```

#### 2. PIR触发模式 (MODE_PIR_TRIGGER)
```cpp
适用场景：安防监控、野生动物观测
配置示例：
  PIR_TIMEOUT_MS = 30000; // PIR触发后30秒内不再触发
```

#### 3. 混合模式 (MODE_HYBRID)
```cpp
适用场景：日常记录 + 事件触发
特点：
  - 定时拍照（默认）
  - PIR触发额外拍照
  - PIR触发后5秒内不重复触发
```

### 高级配置

```cpp
// 夜视配置
const bool ENABLE_NIGHT_VISION = true;
const int LIGHT_THRESHOLD = 500; // 光线阈值ADC值

// 电池阈值
```

## 安装部署

### 选址原则

| 因素 | 要求 | 说明 |
|------|------|------|
| **阳光** | 每天≥4小时直射 | 太阳能板朝向正南 |
| **角度** | 太阳能板倾斜角 = 当地纬度 | 例：北京≈40° |
| **WiFi信号** | 强度≥-70dBm | 测试信号稳定性 |
| **防护** | 避免直接雨淋 | 树下或屋檐下最佳 |
| **高度** | 摄像头 1.5-2m | 最佳拍摄高度 |

### 安装步骤

#### 1. 硬件组装

```cpp
步骤1：焊接电路
├── 按接线图连接所有组件
├── 使用热缩管保护裸露导线
└── 确认无短路

步骤2：测试电路
├── 先不装入外壳
├── 单独测试各模块
└── 确认太阳能充电正常

步骤3：装入外壳
├── 固定ESP32-CAM（用热熔胶或螺丝）
├── 整理线缆（避免挤压）
└── 密封外壳
```

#### 2. 软件烧录

```bash
# 1. Arduino IDE 配置
工具 → 开发板 → ESP32 Wrover Module
工具 → Partition Scheme → Huge APP

# 2. 修改WiFi配置
编辑代码中的 ssid 和 password

# 3. 上传程序
点击上传按钮，等待完成

# 4. 测试
断开GPIO0，按复位，观察串口输出
```

#### 3. 实地部署

```cpp
部署检查清单：

□ 太阳能板朝向正确（正南，倾斜角=纬度）
□ 太阳能板无遮挡
□ 外壳密封完好
□ 摄像头角度调整到位
□ WiFi信号测试正常
□ 测试一张照片保存成功
□ 记录安装位置和时间
```

## 安全注意事项

⚠️ **重要提醒**：

1. **电池安全**
   - 不要短路电池正负极
   - 不要过充过放
   - 不要加热或焚烧电池
   - 使用带保护板的电池

2. **防水安全**
   - 确保所有接口密封
   - 定期检查密封胶
   - 避免长时间浸泡水中

3. **设备安全**
   - 避免雷击（加装避雷针）
   - 防止动物破坏（加装保护网）
   - 定期检查固定支架

4. **数据安全**
   - 定期备份重要照片
   - SD卡建议每月格式化一次
   - 多设备冗余备份
