## 接线图

### 1. USB-TTL 下载接线

用于烧录程序和调试：

```
ESP32-CAM          USB-TTL模块
─────────          ───────────
  GND    ────────    GND
  5V     ────────    5V
  U0R    ────────    TXD
  U0T    ────────    RXD
  GPIO0  ────────    GND (下载时短接，运行时断开)
```

### 2. 详细接线表

| ESP32-CAM | USB-TTL | 说明 |
|-----------|---------|------|
| GND | GND | 共地 |
| 5V | 5V | 供电（不要用3.3V，电流不够） |
| U0R (GPIO3) | TXD | 串口接收 |
| U0T (GPIO1) | RXD | 串口发送 |
| GPIO0 | GND | 下载模式（下载时接GND，运行时不接） |

## 烧录步骤

### 1. 安装 Arduino IDE

1. 下载并安装 [Arduino IDE](https://www.arduino.cc/en/software)
2. 添加 ESP32 开发板支持：
   - 打开 `文件` → `首选项`
   - 在 `附加开发板管理器网址` 中添加：
     ```
     https://dl.espressif.com/dl/package_esp32_index.json
     ```
   - 打开 `工具` → `开发板` → `开发板管理器`
   - 搜索 `ESP32` 并安装

### 2. 配置开发板

选择以下配置：

| 配置项 | 设置值 |
|--------|--------|
| 开发板 | ESP32 Wrover Module |
| Flash Mode | QIO |
| Flash Size | 4MB (32Mb) |
| Partition Scheme | Huge APP (3MB No OTA/1MB SPIFFS) |
| Upload Speed | 115200 |
| Port | 选择你的COM口 |

### 3. 烧录程序

1. **接线**：按照上面的接线图连接 USB-TTL 模块
2. **进入下载模式**：将 GPIO0 连接到 GND
3. **连接电脑**：插入 USB-TTL 模块
4. **选择端口**：在 Arduino IDE 中选择正确的 COM 端口
5. **上传程序**：点击上传按钮
6. **等待完成**：看到 "Connecting..." 时，按一下 ESP32-CAM 的 RST 按钮
7. **完成烧录**：看到 "Done uploading" 表示成功

### 4. 运行程序

1. **断开 GPIO0**：将 GPIO0 与 GND 的连接断开
2. **复位**：按一下 RST 按钮
3. **查看输出**：打开串口监视器（波特率 115200）

## 供电方式

### 方式1：USB-TTL 供电（调试时使用）
- 直接使用 USB-TTL 模块的 5V 供电
- 适合调试，但不适合长期运行

### 方式2：独立 5V 电源（推荐长期使用）
```
5V电源 ────┬──── ESP32-CAM 5V
           └──── USB-TTL 5V (如果需要调试)
GND  ────┬──── ESP32-CAM GND
         └──── USB-TTL GND
```

### 方式3：锂电池供电（便携使用）
- 使用 3.7V 锂电池 + 升压模块升至 5V
- 或使用 2节 18650 电池串联（7.4V）+ 降压模块

## TF卡说明

### 支持的卡类型
- Micro SD (TF卡)
- 容量：最大 32GB (FAT32格式)
- 建议 Class 10 高速卡

### 格式化要求
1. 使用 FAT32 文件系统格式化
2. 分配单元大小：默认即可
3. 卷标：可以不设置

### 文件结构
程序会自动创建以下目录结构：
```
/photos/           # 照片存储目录
  ├── photo_000001_001.jpg
  ├── photo_000001_002.jpg
  └── ...
```

## 常见问题

### Q1: 上传失败，显示 "Failed to connect to ESP32"
**解决**：
- 检查 GPIO0 是否已连接到 GND
- 在上传时按一下 RST 按钮
- 检查串口选择是否正确
- 尝试降低上传波特率到 57600

### Q2: 串口输出乱码
**解决**：
- 检查波特率是否设置为 115200
- 检查接线是否松动
- 确保 USB-TTL 模块与 ESP32 共地

### Q3: SD卡初始化失败
**解决**：
- 检查 TF 卡是否插好
- 确认 TF 卡格式为 FAT32
- 尝试更换 TF 卡
- 清洁 TF 卡金手指

### Q4: 摄像头初始化失败
**解决**：
- 检查摄像头排线是否插好
- 确认摄像头模块没有损坏
- 检查电源是否稳定（5V 1A以上）

### Q5: WiFi连接失败
**解决**：
- 检查 WiFi 名称和密码是否正确
- 确认 WiFi 是 2.4GHz 频段（ESP32不支持5GHz）
- 检查信号强度
